Small status pill for transaction/application state.

```jsx
<Tag variant="primary">Eligible</Tag>
<Tag variant="success">Approved</Tag>
<Tag variant="warning">Pending</Tag>
<Tag variant="error">Declined</Tag>
<Tag variant="neutral">Draft</Tag>
```

5 variants, each a tinted-background + matching-color-text pill, `999px` radius, `12px` bold text.
